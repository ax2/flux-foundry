# Stage-30 中央空列旁的低位移动积木

黄铜球在 x=210 以近零横速弹回，前三次接球的普通反弹均沿中央空列。第四次才达到原有多块积木辅助条件。第三次接球时，邻近低排移动圆块提供了一次短程可达的接触。

远征无气流、至少五块积木、已有两次空接且无命中满八秒时，球和挡板都需接近中央、横速很小，并有移动积木靠近低位中央空列。用现有搜索在绝对倾角 0.20 内选择接球后 0.45 秒内预计命中的反弹。普通反弹预计可命中时仍优先使用普通反弹。实际倾角经真实挡板接触改变出球。

比较更宽的中央条件、可用倾角与起算高度。选定邻近低位移动积木的范围，因为它保留了目标的第二发 97 次命中，且保护其他 263 局。在该局中，有效接触增加也延长了整局飞行时间。这项改动适用于空转间隔，整局时长作为单独的体验指标记录。
