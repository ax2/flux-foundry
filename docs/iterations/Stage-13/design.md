# Stage-13 低位/移动积木残局设计

只改已有可见机械面的校正，不增加玩家按钮、接球预算或弹珠寿命。原PNG、原图尺寸、渲染采样与存档规则保持不变。

预测以当前固定步的球和挡板起点为基准，使用真实catchPaddle弧面/运动参考系；近挡板改为约25ms间隔校正，其余约80ms。移动积木按预计接触时刻的正弦位置/速度计算；弱擦碰也执行物理反射而非穿过积木。距离评分使用真实轮廓，17个粗角及当前角后在两个较好方向细化8个角，不用增加能量补偿几何误差。

只剩1–2块且都在y>=540时，从4秒/2次无命中接球后开始可见校正，范围仍不超过±0.48；其他场景沿用8秒/4次及原有阈值。次数用于识别无进展，绝不是次数额度：接球继续生效，无限制。所有速度改变仍来自实际碰撞和原有供能/重力/气流，预测只读。

360局专项从5个官方完整关卡出发，覆盖12材质尺寸、镜像和100/133/200ms操控；自然打到1–2块时逐步记录。不能把直接删掉其他积木、注入残局或搜索上限当作真实通关。加入20秒稀疏间隔回归门槛，另保留60秒全局调查门槛，区分局部与整局最大间隔。

物理帮助改动使部分旧回放步数变化，使用原自然求解器重新生成52份正常/镜像路线，仍逐步断言完整原球自然落底。旧单测中的最低6次接球改为发生接球：更快脱离旧循环不是错误；有效命中、触发校正、原球身份与落底断言保留。另有持续接球20次以上的高耐久测试独立验证无限接球。

风险：脚本触控时序变化会改变球路；历史35秒UI场景不保证每次复现。算法控制不是人类胜率，桌面Chrome不是实体手机性能；当前改进不是所有可能轨迹的形式化证明。保留输入记录、低位积木完整位置及分材质截图，避免同关不同材质证据互相覆盖。
