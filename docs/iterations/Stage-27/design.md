# Stage-27 低位积木排的侧壁反弹

seed 9011 的大号橡胶在远征第四波进入四块同高低位积木的残局。长段开头 8.73 秒都在飞行，第一次落回时挡板已到右侧极限。普通反弹先折返右墙，穿过积木高度时仍偏右。旧辅助要有两次空接才提前预测，所以两次可用窗口都错过。

保持原八秒门槛。远征还有至少三块且都在 y=580 或更低时，靠墙接球可以立即比较普通反弹和候选角度。普通反弹预计有有效命中时维持它。仅在候选预报能扣数时才提前准备可见挡板面，沿用已有倾角和供能上限。球从真实接球才改变方向。

采用第一接方案。第二接也改善原病例，但第四发飞行约 168.07 秒，第一接方案为 58.08 秒。把 Stage-26 的帧对齐外推到多块球路会让已改善的小号黄铜从 11.15 增至 13.97 秒，因此保留各自经过验证的适用范围。
