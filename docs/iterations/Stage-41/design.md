# Stage-41 中号黄铜的低排接球

两条回放前三次接球的横向速度都接近零。球心沿 x=210 穿过低排空隙。第四次接球才有倾角，两条路线分别在约 0.09 秒后命中。这里的气流为空。

在一次空接之后，中号黄铜可以在第二次接球预报中尝试两组近侧组合。移动方形弹簧对固定三角，倾角上限 0.28。固定方形弹簧对移动电容，倾角上限 0.301。两组都要求球心与估计积木边缘至少相距 2.5 个球半径，以及同高低排、普通球径和挡板、居中下落。前一阶段的三种倾角及 2.9 个球半径门槛优先。

原角度能命中时保留。新角度需要预报接触后 0.45 秒内可有效命中，且实际反弹仍来自挡板接触。更宽的材质尺寸候选影响两条钢珠路线并降低有效命中，因此本次仅覆盖已验证的中号黄铜组合。
