# Stage-09 设计与证据修复

## 自然回放
生产Game移除recall。求解器完整克隆当前模拟状态（包括运动时间、随机数、挡板和库存），每发只能自然落底。180模拟秒是搜索观察上限，未结束候选被丢弃，不能finish后进入下一发。fixtures只存选珠、角度、自然回收时的步数，默认挡板居中；正式测试检查合法角度、原球身份、完整过槽、结束帧和三星，不接受额外操作字段。

## 重复轨道
接球记录最近8次入射位置和速度。每次积木有效扣1即清空；新接球与历史状态相近（x差<10、vx差<25、vy差<35），连续3次相似时启动可见挡板微倾（斜率0.18），下一次碰撞按新金属面法线反射。朝剩余目标方向倾斜；已有倾斜再次重复则翻向。不会直接推球、扣接球次数、改变数字伤害或按时间删球。绘制曲线和碰撞面共享抛物线加线性斜率；仍允许有进展的长回合。阈值是工程回归参数，不是已证明的最优手感。

局部低速支撑、闸门/柱子反复接触仍沿用显式让位自然落底。目标完成继续自动放行。

## 稳定存档
flux-save采用schema=1，rulesets按规则版本分开存records/ranks，当前paddle-natural-1。旧flux-challenges-v3…v8及v8排行经逐条校验，一次迁入legacy，保留原键及迁移来源标记，重复加载不覆盖。某个版本损坏不影响其他版本。设置新增历史成绩入口；历史星级不自动认证当前布局。声音与选珠仍沿用原稳定偏好键，分别读取，损坏偏好不再清空进度。

## 本轮范围
修复回放、停滞、存档和文档，不重排关卡、不改每击减1、不限制接球，不加入额外主动操作。算法胜率不等于人类胜率。图片压缩、分模式排行、音效扩展和真人试玩留待后续。
