# Stage-57 放大橡胶珠与双层钢弹簧球路

两条远征球路的普通反弹在第三次接球时仍预计无有效命中。沿用现有预测和挡板机械面，先验证普通反弹，再只允许短程能直接命中的轻微偏转。偏转通过挡板接触生效。

- 大号橡胶珠同时获得放大和挡板加宽，且两项效果都仍剩至少 1 秒。低排三块固定积木都在球的同一侧，包括两个六边形弹簧和一块菱形。上方横风朝场心外侧。居中的低横速球在两次空接后才启用这一候选，按当前球半径、挡板宽度与气流预测，倾角上限 0.287 弧度，预计有效碰撞需在接球后 0.85 秒内。
- 大号钢珠无气流和临时放大或加宽。球在中央竖直空列下落，固定钢弹簧和固定六边形在一边，两块薄板及高一层的移动六边形弹簧在另一边。两次空接后可在 0.24 弧度内偏转，仍使用普通短程判定的 0.45 秒窗口。

两条条件按材质、几何、气流和当前状态识别，沿用玩家对挡板位置的控制。命中仍只减 1，接球次数不限，发球由原球自然落底后推进。
