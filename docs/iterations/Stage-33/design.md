# Stage-33 放大钢珠与加宽挡板

远征第 11 波的四块积木都在球左侧，其中有一块低位移动弹簧。第一次靠右接球后，弹珠仍沿右侧上行。第二次时挡板已经加宽、球径仍放大，普通反弹在积木排下方穿过空位。第三次接球时球径已恢复，需要更大的倾角才能碰到同一块弹簧。

两种临时宝物效果同时生效、已有一次空接、连续无命中至少 7 秒时，如果至少四块积木全部位于弹珠同一侧并有低位移动弹簧，先检查普通反弹。只在球仍下降、球心接近挡板中心且横速较低时检查小倾角。预报使用当前子步、宝物效果、积木运动、气流和真实球径，保留能命中的原挡板角度。只有 0.10 倾角内能在接球后 0.45 秒内预报有效命中时，才准备机械面。

实球在 t530.8667 接球，t530.9833 击中移动弹簧，数字 31→30。命中发生在气流区域下方。球路改变发生于实际挡板接触。
