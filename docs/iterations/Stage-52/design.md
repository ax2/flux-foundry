# Stage-52 低排固定弹簧旁的回弹

靠中央的固定钢弹簧与对侧积木之间留出空列。若大号钢珠连续竖直往返，首接时用实际球半径、挡板面和移动积木的相位预报可达的短程接触。普通反弹预报可命中时照常接球。否则只有预报的有效命中在 0.45 秒内时才准备轻微倾角。

适用范围是无风、原宽挡板、无临时变径，且低排恰好符合以下结构之一。固定弹簧另一侧若为移动电容和固定电容，并有同侧固定六边形，使用 0.26 弧度上限。三块布局中，另一侧一动一静的钢方块采用相同上限。若两侧是固定三角，采用 0.18 弧度上限。条件按布局和相对位置判定。倾角只在真实挡板接触时改变球路。

全布局通用的候选曾令部分回放损失命中甚至少进一波。缩小范围后，三条目标的首次有效落点分别是移动电容、固定弹簧和移动钢方块，接球至命中分别为 0.100、0.183、0.108 秒。每次撞击只扣一点耐久。
