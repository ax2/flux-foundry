# Stage-52 固定弹簧旁的三条垂直空转

Stage-51 后，固定 456 局的最长剩余来自 1229、421、934 的大号钢珠跟随挡板回放。三条均在第 2 发、第 2 波达到 15.275 秒无命中。结束前该发有效命中分别为 53、45、30，下一版保住这三项下限与整局推进。

三条都由 x=210、y=566.98 的近纯竖直上抛进入空转。第一次到第三次接球分别在上次有效命中后约 3.80、7.65、11.40 秒，挡板倾角为 0；第四次 15.15 秒才改变。场内无风，低排 y=609 左方的 x=138 固定钢弹簧是三条共有目标；右侧分别为含移动电容的组合、固定三角和含移动方块的组合。既有大号钢珠低排助手要求四块均固定并有近侧三角，排除了这三条。下一步用实球对照验证是否能提前一轮命中共有弹簧，找出可共同覆盖而不改写其他路线的条件。

粗筛 36 组参数 × 3 条路线，各做前两发和完整局。单一角度上限没有同时满足三条的目标发命中要求。首接 0.26 在两种有移动积木的路线保住了本发命中：1229 为 53 次、最长 10.275 秒，934 为 44 次、最长 3.908 秒；首接 0.18 在全固定的 421 保住本发 45 次，最长 7.967 秒。三条完整局均达到基线波次、发数及总命中下限。根据积木是否移动组合角度上限，已启动隔离候选的 456 局对照。它还不是正式修复。
