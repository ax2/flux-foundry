# Stage-04 / v0.4.0 进行中 — 2026-11-07

## 用户修订与目标
- 剩余弹珠应放在顶部原有三角出球仓中，移除独立库存栏，释放场地空间。
- 积木只保留数字，移除重复血条；数字直接表示还需有效撞击次数。
- 增加策略组合，实际多轮界面游玩，并检查卡球、材质和尺寸优势。

## 本轮计划
1. 原仓内呈现所有未发射球，可点选调序；发射后移除该球，场内仍一颗且无拖尾。
2. 增加上升气流/风阀与双核心组合，补足材质尺寸的关卡应用，不给材质伤害加成。
3. 全12种弹珠的无主动收球长程模拟、定向物理情景与可解回放；真实界面多轮操作与截图检查。
4. 测试、构建、Windows启动、公开部署、版本与长期档案同步。

## 初始检查
- 当前v0.3.0库存栏占约80像素，三角仓仍空；积木同时绘制数字与血条。
- 材质已有磁性、质量、恢复系数差异，但原关卡缺少上升气流，橡胶的气流特性用途不够明确。
- 现有防卡有两次可见脉冲和机关退让，需以无主动收球样本检查，不能把20秒测量截断冒充不卡球。
- 使用frontend-testing-debugging技能；Browser plugin not available，采用项目Playwright和原生界面操作。用户要求持续档案，因此保存阶段截图与测试数据。

当前：开始实现，未验证结果不提前宣布通过。

## 追加修订与首轮发现
- 用户要求写实气流动画、不规则风区、去掉积木功能文字、增加墙面补能，已纳入本阶段。
- 首轮2592次无主动收球模拟，发现6例陶瓷珠在第5/12关闸门上方垂直反弹超过90秒，速度非零但没有进展。增加同一被动表面四次近位接触的救援触发，不删除弹珠。
- 修复后2592次全部自然落底，最长44.075秒，救援脉冲27次；没有静止死锁或中途删除。另用全封闭、HP10000的非实关平台测试，陶瓷珠仍能连续有效扣血，106.12秒后气脉冲退让落底；记录为压力情景，不把100秒观察边界误当游戏超时。
- 新增六关（19–24），包括上升风井、风阀翻转、窄门双核心与强侧风横渡。金色侧壁段每球每段3次补能，法向加能上限与积木相同，切向速度保持。
- 当前12组合统计：大陶瓷平均命中最高，但没有覆盖所有关卡的优势。统计不包含钢珠主动磁场，不能据此判定钢珠无用；小珠的窄缝、黄铜抗风、橡胶托举另有定向验证。
- IAB实际界面两轮（旧矩形风区候选）：第19关大橡胶直射0命中，正常回收；小陶瓷左偏7次键盘步进，得165分（9次碰撞+1次破坏），正常回收，库存8→6。气流形状调整后的新候选另行实玩。

## 实玩反馈后的调整
- 通过真实DOM输入打完第5、19、24关三局，共27颗球，无主动收球；全部正常回收、没有死锁。采用固定非求解器角度和轮换材质，三局库存耗尽失败，不把这些结果宣称为人类通关率。
- 第19关橡胶直射仅0.61秒且0命中，暴露初次尝试容易直接漏底。增加正下方低耐久蓄能薄板，先把球送回风井；仍需选择斜向球路触及两侧核心。原候选数据保留为candidate，不覆盖历史。
- 第24关实际钢珠直射击碎风阀，气流从上升改下降，得115分后自然回收；已观察到风阀规则生效。去掉闸门文字，用锁扣轮廓表示；绿色开关底部改为机械孔，避免像血条。
- 气流第一稿硬边过于像多边形面片，已按同一受力轮廓加羽化遮罩，消除生硬边界。
