# Stage-04 平衡、实玩与发布前评估

## 用户可见变化
库存改为三角仓内真实材质弹珠，不额外占高度；每发射一颗对应库存消失。积木数字是唯一耐久表示，功能用双层框、线圈和机械孔识别。气流是柔边气雾/细流，侧壁是有亮点余量的金色蓄能段。

## 自然落底和补能对照
24关×12组合×9角度=2592次首球，运行到自然落底，不使用主动收球；90秒是观测界限，不是游戏超时。最终有侧壁补能与关闭侧壁补能各2592次，均全部落底，最长44.075秒，27次救援脉冲。测试强制检查消失前整球已经进入底部，无NaN。
最早候选6例陶瓷珠在第5/12关闸门上90秒还反弹；增加同一被动表面4次近位接触的脱困条件修复。完全封死且耐久10000的人工压力平台，12组合均在120秒内通过退让落底；最慢陶瓷约106秒，期间仍有有效扣血，不能称为静止死锁。
