# Flux Foundry v0.5.0 — 回弹续航与耐久支点

- 底部回收槽增加机械回弹挡板：每颗初始2次，每8次有效命中再充1次，最多额外2次；灯条显示剩余充能。
- 飞行中点击场地或按空格可使用一次上冲气脉冲，把握时机挽救下落、调整球路。
- 远征新增积木按生成层提高数字，每层保证一块明显更耐久的蓄能积木：12、16、20…；金色线圈与铆钉标识，积木仍仅显示数字。
- 拆除高耐久支点可减缓本轮积木上升，在留住反射支点和缓解压力间选择。
- 单球、每击减1、三角仓库存、无轨迹/拖尾、不因时间删除弹珠等规则保留。供能有预算，耗尽挡板后仍会自然落底。

同组864次模拟平均有效命中11.38→27.23、在场13.57→28.56秒；另通过2592次挑战自然回收、72局远征、48套正常/镜像三星路线和58项逻辑测试。模拟不能替代真人平衡验收，少量重珠连击仍可能较长；上冲是否有益取决于时机。完整发布检查见同目录工作日志。

Windows提供便携EXE及校验值，本地保留完整运行目录，无游戏ZIP；手机为Web/PWA。旧版星级保留在原记录，新物理版本独立计分。
