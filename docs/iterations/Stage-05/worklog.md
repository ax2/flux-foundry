# Stage-05 / v0.5.0 已发布 — 2026-11-07

## 目标
用户仍认为弹珠掉底太快。增加可见、有限的补能/回弹手段；新增积木随层增长，每层保证一块数字明显更大的耐久支点，同时保留弱通路。

## 初步设计
- 底部机械回弹挡板：每球2次，接住下落球、反弹回场内；有效碰撞可以赚取最多2次补充充能。
- 主动上冲：飞行中点按场地/空格，使用一次持续气脉冲，由玩家选择挽救时机。
- 远征独立生成层号，普通数字和唯一高耐久蓄能锚点随层递增；锚点保证生成，不受随机空格删除。
- 继续保持每击减1、单球、无轨迹/拖尾、三角仓库存、无球龄删除与现有脱困。

## 验证计划
先测v0.4.0基线，比较同种子/角度/12种弹珠的平均命中、飞行时长、2秒内掉底比例；验证后期多层对局、自然回收、防卡、补能上限。重做24正常+24镜像解、UI与Windows、公网验证后发布。

## 实现与测量（发布前）

- 在修改前保存v0.4基线：864次（8种子×12材质尺寸×9角度），平均13.5689秒/11.3843命中，56次不足2秒，全部自然回收。
- 挡板放在原回收槽内，碰撞面y=707；两格储能灯与8格命中进度显示余量。每球初始2次，每8次有效命中补1次，最多赚2次；目标完成/安全回收会放行。反射保留切向，法向补能48000，上限240000。
- 手动上冲为每球一次、0.32秒向上驱动，正功预算60000，受240000动能上限约束；飞行中点场地或空格。磁场放置模式优先，暂停禁止使用。
- 远征每层唯一保证生成的蓄能锚点，12/16/20…递增；普通积木2–5、4–7、6–9…形成阶梯。锚点增加铆钉外观，不加文字/血条。击破锚点后本轮推进由39降至24，下一层生成机制保持一致。
- 首轮新版864次平均28.5535秒/27.2303命中；1颗大钢珠超过120秒观察窗。跟踪确认持续消耗数字，124.45秒正常回收。将观察窗延至180秒（不是游戏寿命）；最终平均28.5586秒/27.2338命中，6次不足2秒，0未回收。
- 24关×12组合×9角度=2592次挑战自然回收，0未完成，最长49.7083秒；29次可见脱困，0强制安全通道。
- 72局远征首次180秒观察窗有7局截断，均单球已命中100次以上；延至360秒继续核查，72局全部自然用完12颗，未过载、未停滞。固定策略偏保守，不能当成人类胜率。
- 晚点上冲的36组配对：平均整局命中396.25→395.67，平均总飞行385.42→389.46秒。保留该负结果，不宣传上冲必然提升收益；主要续航来自回弹设备与耐久支点。
- 首轮旧测试49/52通过：2套历史关卡路线因物理改变失效，已重新求解48套正常/镜像路线并通过；纯落底边界测试隔离关闭新增挡板，不改变生产规则。新加6项边界/预算/层级测试，最终58项通过，构建通过。
- 浏览器三视口、完整UI对局、Windows启动与公开发布正在验证；此处不提前记作通过。
