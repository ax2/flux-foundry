# Stage-05 续航与层级设计

增加可以理解、可以耗尽的外部供能，保留自由飞行和被动碰撞规则。弹珠不会因时间耗尽删除；有进展的长连击可以持续，玩家随时主动收球。

| 机制 | 规则 | 策略 |
| --- | --- | --- |
| 回收槽机械挡板 | 每球2次自动回弹；每8有效命中赚1次，最多额外2次 | 打出有效碰撞以延长球路；不增库存 |
| 上冲气脉冲 | 每球点场地/空格一次，0.32秒驱动，60000正功预算 | 下落时可制动，接近斜面时改变碰撞位置；时机不好也可能错过目标 |
| 层级数字 | 生成层n的普通数值2n至2n+3；唯一锚点8+4n | 弱块开路，高数字支点留场更久 |
| 蓄能锚点 | 金色线圈+铆钉；沿碰撞法向供能 | 留着反弹或尽早拆除换取推进减缓 |
| 推进减缓 | 本球拆过锚点：上升24，否则39 | 在连击收益与远征压力间选择 |

沿用侧壁每段3次供能、风区、磁场、自动脱困。挡板补能48000，侧壁/弹簧22000，单次设备供能后动能不超过240000（重力本身不受此截断）。普通碰撞恢复系数、质量、半径不变，每次有效撞击只减1。

新层锚点在中间三列轮换，方块/六边形交替；固定间距保留大小珠通行差异。特殊积木仍只显示数字。挡板嵌入既有底槽，不添加屏幕区域；脉冲提示复用场内连击说明。挑战布局保持不变，新机制全局生效，因此星级采用v5记录键，保留旧记录原值。

风险：更耐久也可能带来少量超过3分钟的重珠长连击；本版不以超时删除解决。固定角度模拟已不足以逼出远征过载，后续需真实玩家验证节奏，不能据此宣称难度完善。上冲并非必然增益。
