# Stage-47 薄板对侧空列与贴墙回弹

934 的移动六边形弹簧位于中央空列一侧，固定薄板在对侧。第二次接球前按实帧子步计算，0.264 倾角上限给出通向薄板的有效角度。实球接球后 0.158 秒命中，耐久 13→12。另一条更晚的候选同样达到 853 次整局命中，选用更早的方案是因为它也缩短了整局飞行。

815 的挡板贴近侧边，接球时球在挡板边缘。普通出球容易向侧壁反射后沿空列往返。四块低排全在同侧，近侧是固定六边形弹簧，气流在目标上方。第二次接球通过实帧预报计算反弹和墙面接触，实球约 0.250 秒后命中，耐久 11→10。保留能有效命中的普通反弹，新的倾角须能在短程内命中。

两种候选均用既有供能，范围限定于常规球径和挡板的中号黄铜。贴墙候选仍用实际气流受力条件进行预报。
