# Stage-51 大号钢珠中央垂直空转

已用 Stage-50 代码复现 7429、大号钢珠、跟随挡板、第 3 发第 3 波，整局最长无命中 15.283 秒。该发 8 次有效命中，飞行约 21.24 秒，十五发都由同一原球完整落底结束。

峰值窗口始于 (x=210) 的竖直上抛，风区为空。板上有两块移动弹簧、左侧固定六边形和右侧固定菱形。前三次空接分别在上次命中后约 3.20、7.33、11.31 秒，球的横向速度近于零，挡板面仍水平，沿同一列往返；到约 15.13 秒第四次接球，挡板才倾斜。下一步检查各次真实接触时的移动积木相位，优先找能提前命中且不损失本发 8 次命中的可见反弹角。观察上限不能回收球，截图和原画质保持。

先加固定局回归，旧版因超过 13 秒阈值失败。短程扫了 90 个候选，对照介入时机、是否使用实际接触子步，以及挡板倾角。第一次接球有只需约 0.12 秒即可打中低位移动弹簧的球路；多种角度保住第 3 发至少 8 次有效命中。晚两次接球的候选则可能减少为 4 次命中。接着对照完整 15 发和 456 局矩阵，不用首三发结果代替整轮结论。
