# Stage-51 交错移动弹簧的提前接球

第 3 波中央间隙里，钢珠横向速度近零。即使等移动积木摆动，前三次水平挡板仍把球送回同一条竖线。原来的中央移动积木条件要求更多积木或同排，普通辅助要到第四次接球才准备角度。

当上下两块移动弹簧分列中央两侧、固定积木留在外侧、没有风和临时增益，若大号钢珠长时间从中央几乎竖直落回原宽挡板，就在下一次真实接球前检查短程回弹。保持预报可命中的普通反弹；其他情况下，只允许能在 0.85 秒内产生有效接触的轻微挡板倾角。预报用真实接球子步，弹珠仍由真实碰撞改变速度。0.221 弧度是允许搜索的上限，目标接球实际用约 -0.186 弧度。

此次对照中有 90 组时机、预测方式和倾角的粗筛，以及 101 条首次接球角度的整轮细筛。粗筛的 0.20 把整轮峰值降到 9.75 秒，但整局飞行增加约 209 秒；0.221 将本发空转降到 3.33 秒，整局只多约 2.51 秒，且提高本发与全局命中。没有修改接球次数、能量上限、回收条件和贴图。
