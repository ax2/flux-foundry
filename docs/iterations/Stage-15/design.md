# Stage-15 重球高位目标蓄能设计

修复限定在既有挡板的可见蓄能，不改图片/尺寸/材质、风场、发射能量、接球或寿命规则。

确定性复现：seed1012 / 第13关 / 黄铜大球 /2.59 / follow居中每14固定步控制。首球135.0083秒、55次接球，最后只剩x90 y340的1耐久横条，最长27.6秒不扣数。无风、闸门或其他被动障碍。旧轨迹连续反弹的vy约307→340→349→356→362→378→383，重球逐渐攒够高度后才碰到横条。是上行动能不足，不是卡住或球龄删除。

预测先求实际弧面接触，按最近仍有效目标的下缘、球半径计算高度差h；所需竖直能量下界为m*(240h+90²/2)，包含有用撞击余量。与预测反射后的竖直能量比较，为当前候选准备补能。单次仍18000–40000，实际补能仍由原energize在真实挡板接触时执行，新增能量以240000门槛限制，不抹去已有更高的重力/运动能量。当前已准备的补能不会凭空下降；接球后恢复常规待命。

guidedRebound返回倾角与补能计划；原guidedTilt保留只读兼容包装。Game只设置可见机械面和蓄能值，不改半途球速、球位置或目标数字。单位检查证明准备蓄能前后的活球只有正常重力变化，直到真实catchPaddle才增加能量；规划输入保持不变。

同一控制器/布局/初角重放，案例27.6→15.625秒，首球135.0083→122.9417秒，55→51接球。第18钢大、第2黄铜大、第16黄铜大同类案例分别24.525→15.4833、23.2917→14.1833、22.8917→15.35秒。控制器没有从居中follow换成主动偏心steer。

广首球1872矩阵新增25秒回归门槛，并保存20秒以上峰值状态；观察上限只记录失败，不结束球。修复后整体最大20.8秒，尚有2例超过20秒，不宣称全部轨迹无循环。2496新种子首球最大20.54秒，均自然结束。
