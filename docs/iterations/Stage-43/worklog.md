# Stage-43 大号陶瓷在三块方形积木间直弹

Stage-42 的 456 局矩阵剩余峰值在 934 大号陶瓷第 3 发，15.62 秒无命中。本发 15 次有效命中，整局 493 次，15 发自然收尾。该发的三块积木同高 y=585。固定弹簧在左，普通移动方块和固定方块在右，场上无气流。

第一次接球时球仍受放大宝物影响，半径为 21.6。第二次接球恢复至 16，前三次横速仍近于零，从中央空列穿过。第四次接球产生横向位移并命中。首轮 50 个隔离候选中，0.16 上限可让第二次接球后更早命中，本发最长 7.67 秒且命中 15→28，整局最长 9.22 秒且命中 493→617。正在对照 456 局矩阵，生产源码尚未接入。

隔离和接入后的矩阵相同。456 局全部自然结束，仅 934 大号陶瓷跟随路线变化。173 项逻辑、121 项浏览器与构建通过。三轮 Chrome 控制器触控中，934 五发和 7429 四发均自然回收，第 19 关三发三星。Stage-43 保留本地。后续峰值为 87 中号黄铜在第 3 发约 15.62 秒。
