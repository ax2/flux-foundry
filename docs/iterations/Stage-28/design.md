# Stage-28 同高低位积木之间的直通球路

远征剩三块低位同高积木时，挡板中部的小横速反弹可能反复穿过空列。大号陶瓷案例的第二次接球位于 x≈178，普通反弹上升到积木高度时已偏到 x≈181，错过左侧弹簧。直接小倾角反弹则能接触弹簧侧面。

早期准备沿用八秒门槛，并且只检查第一次空接之后。球位于挡板中部、接近垂直下落且左右都有同排积木时，候选绝对倾角上限为 0.22。保留预报可命中的普通反弹。只有倾角搜索预报能在接球后 0.45 秒内有效命中时才采用候选。命中用时从同一次预测返回，省去重复模拟与轨迹分配。

真实反弹仍依靠原来的曲面接触、能量上限和连续外力。普通及贴边辅助沿用原触发路径。没有改变回合寿命、接球次数、关卡参数、原图或存档。
