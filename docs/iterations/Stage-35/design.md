# Stage-35 固定低排中央空隙

当远征剩三块固定、同高的低位积木，球和挡板近乎完全居中，来球近乎垂直，无气流，且已有一次空接、无命中至少 7 秒时，检查挡板能否把第二次反弹送到中央空隙两边的平直积木面。只在现有角度无法命中、且 0.22 以内的角度预计能在 0.45 秒内命中时，准备机械面。碰撞发生前球的运动仍由现有重力与碰撞计算处理。

先尝试了左右有任意积木的宽松条件，456 局里有五局变化。另有一局最长无命中增长，一局有效命中减少。比较首次分歧，目标路线两侧近处都有钢质方块的平直面，另外几条缺少这一几何条件。加入两侧可达平面后，候选只改变目标路线。

正式回放 t394.6917 接球，t394.8667 命中左侧方块，耐久 12→11。右侧弹簧也有可达预测，但本次实际挡板角度选中了左侧。
