# Stage-22 病例定位与防退化

本轮对象是Stage-15记录的两个历史病例，而不是新发现的20.8秒回归。第10关黄铜小/2.59/seed1009、第21关陶瓷大/π/2/seed1020；固定1/120步，每14步follow合法移动挡板。

## 已有修复的因果证据

- 第10关：剩y440横条和y540移动圆块，早期校正原本仅覆盖全部y≥540的目标，需8秒/4次空接才介入；错过两次接球窗口后又进入柱区。Stage-16对所有1–2块残局采用已有4秒/2次空接准备。历史柱修复单独试验仍20.7583秒，说明原因不同。
- 第21关：两柱交替弹跳且接触点漂移，旧12px单点计数被重置；最后一次接球在gap6.45秒，之后挡板无法介入。Stage-16各柱独立累计至少3次分离碰撞、且无扣数至少8秒后可见回缩。触发当次反射仍正常，下一次接触才让行，不改球的位置/速度/耐久。

以上来自已存Stage-16 design及two-before/peg-only/after附件，不宣称本轮重新运行旧版本。Stage-19/20进一步改善实际气流/移动目标预测和受限接触做功；本轮重跑当前版本可确认结果，不能仅凭结果把改善全部归因于某一后续改动。
