# Stage-44 加宽挡板的低排偏心接球

本轮球半径为 12，挡板从 96 加宽到 144。沿同样的输入跟进，第二次接球时球略偏离挡板中心，普通反弹的横速仍接近零。前一阶段的普通挡板方案从条件上无法处理这段球路。

加宽挡板上的中号黄铜在中央附近偏心下落、已有一次空接、场上无气流、四块同高低排且固定方形弹簧与移动薄板可达时，试算最高 0.23 倾角。普通反弹预计命中时保留。预报仍用实际物理子步，并要求短程有效命中。候选实测第二次接球后 0.133 秒打到左侧弹簧，耐久 13→12。

0.14 和 0.23 候选均保住目标发命中，且空转明显缩短。选 0.23，因为在该回放中目标发和整局飞行均更短，整局命中仍从 588 增至 626。
