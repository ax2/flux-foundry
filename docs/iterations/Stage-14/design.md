# Stage-14 组合机关与风场球路

原始PNG/分辨率/材质渲染保持，气流力与羽化边界保持，接球次数和原球寿命不设上限。仅修复被动机关组合导致的空转。

第5关镜像陶瓷中球200ms输入，4块尚存时33.79秒无命中。真实接触记录显示闸门顶部接触x176→188→200→211……，vx约4.23，反复弹到上方再回来；旧12px锚点累计漂移不断重置检测，球不碰挡板，靠挡板改向无能为力。该关没有风，不能归因于气流。

正式修复：同一锁定闸门的独立实际碰撞（间隔>=0.25秒，防子步重复）积累压力；至少3次且8秒无有效扣数后可见临时卸压。完整原球穿到另一侧、与闸门完全分离后复位，不在原球内部合闸。不改原球位置、速度、数字或关卡目标；开关击碎仍永久打开闸门。每次有效扣数重置压力，回合结束/下一发清理临时状态。黄色端柱/虚线与3个压力点区分临时通行，永久开闸为绿色；说明放设置帮助，不给积木加文字。

预测此前把闸门/反弹柱接触当作候选路径终止。现在保持实际被动反射并继续计算气流、其他积木与碰撞力，候选仍只读。没有减弱风场，没有把气流变成固定推力或忽略碰撞。

消融只做诊断：第26关镜像黄铜小球117ms输入，正常多块间隔24.95秒，去风5.23、预开闸13.09，说明组合有影响，但这些改变了条件的胜局不算正式回放。正式480局均从完整官方关卡开始，只有合法选珠、瞄准和挡板输入；无布局/状态注入。
