# Stage-26 对齐远征残局的接球预报

旧预报根据当前速度给每个小步取上限。实际引擎在 1/120 秒帧开始根据速度选整数个子步，并在第一子步接球后继续完成该帧。第 4 波 t348.208 的探针中，旧预报比实球约晚 4ms 接触曲面。两种出球仅替换坐标和速度做诊断对照，预报出球后 1.15 秒扣数，实际出球在同一窗口内没有命中。

远征仅剩一块低位移动积木且无命中满 8 秒时，让预报复用实际的子步数、挡板行程和每帧积木位置。接触后沿同样的子步完成该帧，再使用原有长程估计。整段对齐与只对齐接球在 72 局固定矩阵里得到相同结果，近场修改的范围更小。预报仍固定当前挡板目标，后续玩家动作、宝物与机关变化可改变实际路线。

接触时继续使用现有金属曲面的法线与能量上限。保留真实碰撞减 1、无限接球和原球完整落底回收。8 秒仅决定预报何时换用帧对齐。固定关卡、存档格式和 PNG 逐字节保持。
