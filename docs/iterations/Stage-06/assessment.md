# Stage-06 评估

底部开放后，26关×12组合×9角度共2808次无技能首球全部自然回收，最长44.075秒。该数据仅检查数值稳定、自然落底和脱困，平均命中降低是移除自动挡板后的预期变化，不宣称比v0.5更长续航。

52套正常/镜像布局可在三星预算内回放；路线求解允许主动收球，不与自然回收测试混用。新25关1球算法可解，新26关3球算法可解；说明无需技能也能完成。

3局真实时间UI自动游玩为390×844、混合材质尺寸、固定非最优角度、4倍速、下降到y540后使用↑：第25关1颗赢（未用技能），第26关10颗失败（10次脉冲），第24关12颗失败（4次脉冲）。共23颗、14次脉冲，均自然落底，无脚本状态修改。首轮有测试点击竞态，已在日志记明并用安全的技能按钮重测。不能把这一胜率当真人胜率，也不能说主动技能必然通关。

59逻辑测试、159UI检查通过。三视口1440×1000、390×844、320×568均检查溢出、暂停、触控、升级、加速恢复、库存与离线；截图为金属深色主题。清理细字后按钮与增强数值更清楚，短屏增强卡片可滚动。Windows完整目录自动冒烟与507×934便携版手动发射/脉冲通过，截图记录非磁性陶瓷珠消耗1格，连续输入未重复施力。

限制：4倍速时小轻珠可能很快落底，需要玩家主动切回慢速或提前使用技能；简化气脉冲视觉为短时细流，仍可继续提高气雾质感。实体Android/iOS、低端设备帧率、长期真人难度尚未验收。旧自动挡板相关的历史报告保留，不倒改历史结果。
