# Stage-06 主动操控与节奏设计

底部开放让球路有风险。把v0.5自动挡板的续航转为玩家控制的气脉冲，任何材质都能参与，钢珠仍保留磁场优势。点按方向只施加短时有限力，不瞬移、不强制速度、不额外扣血。↑按钮用于快速救球，场内点按用于精准转向；每8有效命中赚一格，最多2次，鼓励准确球路。

1/2/4倍速仅改变每帧推进多少个固定物理步；用户操作技能回到1倍。缩短长连击等待，保持瞄准与救球时间。按钮使用可辨图标和数字，规则在帮助中解释。

三选一以跨材质有用为准：能量循环（回弹+供能）、操作次数（脉冲扩容）、操作强度（气室推力+供能），同时保留历史磁场增幅。卡片不再只有小百分比，用升级前后数值与不同色边框展示。恢复系数封顶仍有限，升级后的额外供能受设备动能上限约束。

关卡25先翻风阀再借上升风，26先开双锁、保留核心下方24耐久薄板，选择攻击顺序。两关均在不用主动技能的算法路线下有三星解；主动技能可用于容错或更少发射，不能声称已经证明所有玩家收益。
