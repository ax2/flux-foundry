# Stage-08 平衡与验收

用户修订后玩法已简化为瞄准发射与左右接球；磁场/脉冲/收球、加速、三选一撤销。历史专属测试已退役，通用物理、每击减1、库存、重力、脱困、镜像继续覆盖，另增9项挡板/宝物/运动测试。最终60逻辑测试、生产构建通过；108项三视口UI检查复核中（前轮已全部通过）。

## 多局UI实玩
390×844真实触控事件，按可见开关/核心瞄准，算法每120ms估算落点并移动挡板；无加速/收球/状态注入。第1关2颗通关（6接球、1宝物），19关2颗通关（4接球、3宝物、+1生命），26关1颗通关（29接球、1宝物、+1生命）。共5颗71命中39接球5宝物，最长76.875秒自然结束。证明控制与效果流程工作，不代表真人胜率或手机实体手感。

## 持久模拟
26关×12材质尺寸×3角度=936首球，挡板初始居中。180模拟秒观察时仍有40次持续接球；随后把挡板移开，60秒内全部完整落底，0未完成；累计400次宝物拾取。正常持续接球不是死锁。此处观察上限不是游戏中的回收时间，未删除或瞬移弹珠。

52套正常/镜像三星回放重新生成，考虑运动时间、随机状态和奖励库存。求解器可提前结束候选球用于搜索，不作为自然回收证据。挑战布局和球路改变，旧路线未直接复用。

## 发现与修复
旧工坊文案仍提磁场、关卡说明提主动脉冲，已改成回弹/挡板；快速换关时上一局宝物提示残留，已清空；临时宝物在漏球后预览仍可能残留，已即时重置并增加测试。首轮UI误把“每关都要有移动块”作为要求，修正为初始场地验证运动块、风关验证风力；没有无必要地改动所有关卡。

生命有每局+3上限，临时宝物有持续时间，避免随机奖励无限延长库存。最优控制器三局均赢不代表难度已完善；风力更强后轻球明显更敏感，仍需玩家反馈微调。

## Stage-09 核实修正（2026-11-07）

上述“52套三星回放”含recall，正常有11发、镜像14发在目标未完成时提前结束，不能作为当前UI可执行的完整认证。“正常持续接球不是死锁”表述过强：后续复现第1关600秒6命中233接球的无进展循环。移开挡板只证明可以漏球收集，并未排除此问题。Stage-09已重建无recall自然回放并增加重复轨道回归。Stage-08为未独立发布的本地阶段，公开仍为v0.7.0，后续见Stage-09发布记录。
