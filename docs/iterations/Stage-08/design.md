# Stage-08 设计

## 单一主操作
发射后只需要左右移动挡板：触控在场地任意位置滑动，桌面鼠标移动，键盘左右键也可用。顶部设置自动暂停，排行明确为本机。底部全部按钮、主动技能、加速/慢瞄、三选一均撤销。原三角待发仓和材质尺寸选择继续保留。

挡板弧面中心y675，基础宽96、横向速度上限900。顶面随偏心位置形成法线，边缘反射能转向；在挡板移动参考系中处理反射，有限补能帮助维持反弹。目标完成、清空本轮或安全回收时放行，保持单球自然落底。玩家故意移开挡板可以漏球，不对球施加寿命限制。

## 自动宝物
每颗最多生成3个，首次2.5模拟秒后生成，再隔7秒；位置随机且避开数字积木。宝物12秒未命中消退，扫掠碰撞防高速漏判。所有效果直接生效，无选择弹窗。

| 宝物 | 效果 | 边界 |
| --- | --- | --- |
| ♥ | 生命+1，补进原待发仓 |每局最多额外3颗，待发上限12，场内仍一球 |
| ↔ | 挡板96→144 |本颗14秒，重复续时，漏球恢复 |
| ● | 球半径×1.35，拾取时速度×0.7 |变大12秒，重复只续时，漏球恢复 |

瞬间减速是拾取宝物的效果；之后仍由重力、风力和碰撞决定速度。宝物时钟随游戏暂停。临时效果在回合结束清除，避免下一颗预览与实际发射不一致。

## 环境
运动积木水平正弦轨道，幅度14，按运动参考系反射；轨道范围与其他积木/反射柱保持间距。镜像同时翻转轨道原点与运动方向。气流力2.4倍，渲染流速1.8倍并增强雾层，显示边界仍与受力共享。

## UI与持久化
头部齿轮/排行按钮40px，远征金属入口；设置里收纳声音、特效、玩法、重开。Canvas说明与积木数字有实际像素字号下限。排行只保存本机前十个完成成绩，模式名称校验为本地已知模式；星级采用v8键，旧值保留。
