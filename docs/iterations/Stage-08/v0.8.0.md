# Flux Foundry v0.8.0 — 一球一挡板

- 移除底部全部按钮，取消磁场、主动气脉冲、收球、加速/慢瞄与三选一。
- 新增左右移动挡板：触控滑动、鼠标移动或左右键控制，偏心接球改变反射方向。
- 顶部新增设置和本机排行，声音/特效/玩法/重开收纳进设置；美化远征入口。
- 新增随机宝物，击中直接生效：生命+1、挡板加长、大慢球。生命补入原三角仓，临时效果漏球后清除。
- 新增有机械轨道的移动积木，运动参与反射；气流作用力2.4倍，雾层与流速增强。
- 保持单球、每击减1、无轨迹/拖尾、不因时间消失。卡住时积木让位，原球自然落底。

验证：60逻辑、108界面检查，52正常/镜像三星路线，936次持久模拟；3局触控UI共5颗39接球5宝物全部通关。Windows完整目录与便携EXE启动验证。自动控制器与浏览器视口不能替代真人平衡/真机性能验收。

Windows提供EXE与校验值，完整运行目录本地保留，无游戏ZIP。手机Web/PWA；排行为设备本地记录，无联网排行。
