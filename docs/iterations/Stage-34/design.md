# Stage-34 两种低位接球

大号钢珠第二次接球前，球在三块固定同高积木形成的空隙中，横速接近零，附近弹簧和对侧积木相距至少两个挡板宽。来球正缓慢靠近弹簧，且侧壁补能已耗尽。空转 3.5 至 5 秒时允许 0.11 内的倾角。预测先检查普通挡板接触，并要求小倾角能在 0.45 秒内命中。

小号钢珠在放大宝物持续期间仍使用普通宽挡板。已有一次空接、无命中至少 6.5 秒，来球近垂直，至少四块积木位于同一侧，且低排有可达的移动弹簧时，检查 0.06 内的倾角，同样要求 0.45 秒内命中。两种预报使用当前物理子步，只有实际接球才改变出球。

大号钢珠约 0.067 秒击中固定弹簧，数字 23→22。小号钢珠约 0.183 秒击中移动弹簧，数字 19→18。初版大号条件改动了五条附带球路，后收窄为朝近侧弹簧移动、对侧宽间隙和短回合窗口。约 5.90 秒才到达的另一条反弹留给既有规则处理。
