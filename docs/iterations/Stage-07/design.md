# Stage-07 手机操控与救球节奏设计

轻点飞行场地向上救球；按住进入0.18倍慢瞄，指尖起点固定，滑动选方向，松手施放。短于14世界像素的手抖按上推处理。取消、移出场地松手、失去捕获、Esc均不扣次数；多指忽略非主指针。主按钮↑采用pointerdown，键盘通过click/空格，避免等待抬手造成额外延迟或长按重复消费。待发手机轻点不发射，拖动超过8世界像素才发射。

高速救球：下降且有脉冲、y>=400、预计0.85模拟秒落底时，检查未来0.2秒实际形状碰撞与局部风力。很快撞到支点时保留加速；真正风险窗口给0.7秒0.18倍慢镜头，然后1倍。上升回到y<370后才允许下一次提示。玩家可点加速跳过辅助。预测只用于节奏辅助，绝不画出飞行轨迹、绝不修改正在运行的球/积木。

增强效果不加伤害。保留既有恢复系数/供能/推力参数，补充原选珠栏的◈/✦/≋等级、随施力方向旋转的气流；扩容后立即刷新下一颗显示次数。12种弹珠受控物理对照确认改造真实影响能量与操控，UI对局不能当成严格前后配对收益。

关卡26仅调整数字：右开关4→3、核心20→16、侧块6/9→4/7，留24耐久蓄能支点。降低开门后的重复补刀需求，不改变碰撞形状与每击减1；52正常/镜像解与自然回收重新检查。
