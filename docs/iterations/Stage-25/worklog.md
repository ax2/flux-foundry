# Stage-25 重珠横渡的残局球路

从 Stage-24 本地提交开始，复现第 22 关镜像中号钢珠 17.3667 秒无命中。固定输入为 seed 1021、首发 2.59、第二发瞄准核心，每 14 步使用主动挡板策略。先逐接触比较预报与实际落点，再筛选风区及真实回弹方案。使用原始图集，保留无限接球和原球完整落底。

第二发在无命中 3.68 秒时出现靠墙接球，挡板已抵达左侧极限。原角度让球上升穿过核心高度时偏到 x≈37，核心中心 x=110。反弹预测已找到有效角度，原 4 秒门槛错过这一接。之后三次接球仍在绕回横风。

第一版将部分低位核心的贴边准备提前到 3.5 秒。原病例有效，但试验里另一条球路 7.73→12.43 秒，放弃该范围。增加核心距球不超过当前挡板宽度的条件后，完整固定矩阵只变化两行，两行均改进、耗珠相同。保留的 3.5 秒门槛只决定何时评估，可命中的普通反弹继续保留。
