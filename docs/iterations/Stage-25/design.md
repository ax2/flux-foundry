# Stage-25 横风残局中的贴边接球

第 22 关镜像的中号钢珠在第二发进入单核心阶段时，气流能把偏离的球路带回右侧。原版在 t73.000 的接球前已空转 3.6833 秒，挡板位于 x=70 的行程极限。普通反射从 x≈48 以 vx≈−48 向上，穿过核心高度时在 x≈37，未触及中心 x=110 的核心。只读搜索可以在倾角约 −0.27 时找到后续有效接触，原四秒门槛此时尚未放行。

把提前评估限于四项可观测条件：只剩一个低位核心、接近横向行程极限、核心在一个挡板宽度内、场上有强横风。一次空接且满 3.5 秒才开始。已有反弹能命中则保留，仅接受预测有效命中的候选。待实际接球时，使用现有挡板曲面、倾角和能量上限。最终输入在 t72.983 左右接球，约 t73.44 再命中核心。第二发总飞行 56→33.63 秒，该局剩余最大间隔移到另一段。

筛选同时比较 3.2/3.5 秒、宽范围贴边、同侧和一个挡板宽度范围。宽范围曾改变 13 条整局矩阵记录并增加个别间隔；最终保留更窄范围，正常和镜像仍用同一规则。
