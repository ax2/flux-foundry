# Stage-23 侧边无效回弹与有效路径保护

2026-11-08。目标是缩短第12关剩余18.50秒无命中；原图、单球/每击减1、无限接球和完整落底、关卡/材质/存档保持。

## 原因与证据

准确输入Game(8148,11)、钢中、angle2.478263495133118、steer每18/36步。矩阵的seed8137为组值，实际种子需加index11，不能误用follow。原球于53.6167/40.7583秒自然回收进入aim，最长18.50秒；按同一合法续打规则分别4/2发三星。

长段剩4块、开闸、无反弹柱。球在右边缘反复回弹，挡板中心受场地限制，不能将外侧接球点移到中央；加长时中心上限更靠内。两次空接后即使已8秒无扣数，旧多块门槛仍等待第4次空接，错过第三次接球的可用方案。只读预测在gap10.98–11.40秒给出原限幅内0.32倾角/18k供能有效路线。最终实际准备在gap11.3833秒，正常碰撞后约0.275秒打到低位三角，正常扣1；原最长段缩到11.6583秒。未改变球的中途速度/位置。

gap6.775秒加长状态也存在0.31有效预测，但全局提前到4秒的隔离候选新增29.8833秒案例并损失一项三星，因此保留原8秒等待。不能因为一个宝物出现在长段里就直接删除/削弱宝物。

## 最终实现

只为非稀疏阶段、侧边球心超出挡板可居中范围、已有2次空接且无命中至少8秒的下降球，提前一次检查。先按真实当前倾角/已准备供能做只读普通反弹预测，普通路径已有有效扣数就保留；否则只接受能有效命中的新方案。未命中的“最近方案”不得提前生效。原有8秒/4次后备处理不动。

仍用当前气流羽化、运动积木、闸/柱、球真实半径和质量预测；单次倾角变化≤0.32，原最大倾角和40k单次做功/容量限制不变。写入的是可见挡板倾角/待接触供能，只有之后真实碰撞才能改变弹珠。5项针对测试包含自然原病例、无空中冲量、无有效方案不调整、原可用路线保持；先红3/绿2再修复。

## 为什么保留普通路径

仅提前而每次重新挑“最好”方案会覆盖原先已能打中的路径，浪费玩家瞄准或已准备的机械面。额外提前窗口中普通预测hit时停止改面，让玩家当前轨迹完成。旧正常/后备窗口保留原逻辑，降低变化范围。没有按关卡编号、材料或种子单独改游戏行为。
