# Stage-58 低排空列与错层弹簧

用实际下落位置、横速和挡板位置辨别可重复的空列。只有普通反弹预计不能有效命中，且小幅偏转预计在挡板接触后 0.45 秒内命中时，才准备偏转。两种条件都要求无气流、无放大与加宽效果，维持当前选珠和挡板操控。

- 大号钢珠在同一低排的四块积木之间近竖直居中下落。一侧的固定薄板与钢弹簧对应另一侧两个六边形或菱形，四块里恰有一块移动。第一次接球时即可检查，沿用 0.32 弧度上限，按当前移动位置搜索。
- 中号黄铜珠以低横速在空列内漂移。低排移动钢弹簧与固定六边形在一侧，另一侧有固定薄板与更高一层的移动弹簧。第二次接球时寻找短程碰撞，倾角上限 0.157 弧度。

只通过挡板的真实接触改变球路。后续继续遵循正常的碰撞、能量、单击减 1 和完整落底规则。
