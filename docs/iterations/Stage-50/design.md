# Stage-50 跨场命中最后一块薄板

在第 3 发剩最后一块薄板时，中号钢珠位于对侧。原方案的调整发生在球已远离薄板时，且重复接球的预报使用普通步进。对照将最后一块固定薄板的预报与真实接触子步对齐，并在连续两次空接下比较挡板倾角。范围限定于无气流、常规挡板和钢珠、远离中央且剩 1 点耐久的低位固定薄板。

保留原角度预测可命中的反弹。短程确认延长至 1.3 秒，以覆盖跨场距离。现有空转辅助的接球补能和无可达解时的角度回退继续有效。此样本里首次分歧属于回退角度变化，实球随后经侧壁和另一次接球命中薄板。

0.40 和 0.475 上限都保住该发 18 次命中。选用 0.475，因为整局飞行 852.59 秒，低于原路线 987.58 秒和 0.40 候选的 1128.58 秒。实验中的只接受直接命中方案没有缩短目标空转。
