# Stage-45 两块固定薄板对侧的弹簧

三块积木位于同一低排，两块薄板在空列一侧，方形弹簧在对侧。球心和挡板在 x=210 对齐，前三次普通回弹保持近零横速。第四次才达到原有多块积木辅助条件。

在普通球径和挡板、无气流、中号黄铜近直落且已经空接两次的条件下，按实际碰撞子步预报第三次接球。保留可命中的普通反弹，预计能在短程内命中时允许挡板准备至多 0.302 倾角。真实接球后 0.142 秒击中弹簧，数字 21→20。本次沿用现有标准供能，无需调整挡板补能规则。

对比更早接球、不同倾角、供能及准备时机。选中的第三次接球路线保住第 2 发及第 5 发有效命中和整局命中。一次更早的薄板碰撞虽可把空转压到约 7.85 秒，但整局有效命中降至 852。
