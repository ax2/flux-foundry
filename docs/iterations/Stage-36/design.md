# Stage-36 低排弹簧与六边形之间的直弹

第二次接球前，来球和挡板都接近中央，横速接近零。场上有三至四块同高低排积木，固定方形弹簧与近侧六边形分居球的两边。第二次接球时，连续无命中已达七秒。

用积木半宽估计空隙边缘，要求球心到最近边缘至少三个当前球半径。目标黄铜球的中心到方块边缘为 46，半径 12，条件成立。同布局的大号钢球半径为 16，三倍半径为 48，继续使用现有反弹。规则按实时半径计算，涵盖放大效果。

只有现有角度预报会落空，且 0.24 内有预计 0.45 秒内的命中，才准备挡板的机械面。预报沿用真实子步、碰撞次序与移动积木。三条黄铜的实球均在第二次接球后约 0.167 秒击中方形弹簧，耐久 20→19。
