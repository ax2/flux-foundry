# Stage-54 挡板反弹

815 与 87 的大号钢珠第二发曾连续竖直擦过低排空列。第二次接球时，按低排的实际固定钢弹簧、对侧积木及侧缘形状选择短程反弹。815 的固定六边形组合用 0.32 弧度上限，87 的移动钢方块组合用 0.30 弧度上限。只有原方向预计无法有效撞击时才准备新的挡板角度。

9157 的中号黄铜在第六波有三次接球穿过低排，后续轨迹进入上层横风。场内出现三块固定低排，且弹簧同侧为三角、另一侧为六边形时，预报首次接球能否在 0.45 秒内击中积木。备选角度上限 0.22 弧度，回放真实触点为 0.213125 弧度，实际在约 0.158 秒后撞上固定钢弹簧。

两项调整使用现有挡板碰撞和严格的单次能量上限，球速只在实际接触时变化。原 PNG 摘要与发布版一致。
