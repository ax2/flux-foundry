# v0.2.0 — 弹珠工坊与十二道铸造试炼

2026-11-07，Stage-02 内容更新。

- 弹珠工坊：钢、黄铜、陶瓷、橡胶4种材质，配合小/中/大3种尺寸，共12种组合。尺寸影响碰撞半径与质量；材质影响回弹、磁性和气流响应。每次发射前可换珠，装备本地保存。
- 12个挑战：精密车间、风洞实验室、核心试炼三个章节。规定发射次数内清场，争取三星；支持选关、重试、下一关、最佳星级与最少发射次数记录。
- 新机关：固定反射柱只反射、不消除；局部气流持续施力。无尽模式第4波起可出现反射柱，第6波起加入气流；避开与靶块重叠的位置。
- 固定发射动能，轻珠更快；重力加速度相同。钢珠有磁性，其他材质无磁性。参数为游戏调校，不是材料实验测量值。
- 保留单球、无轨迹/拖尾、每次撞击减1、归零消除、无弹珠寿命与回合超时。挑战清场后也需落入底部或主动收球才结算。

验证：33项逻辑/物理测试、114项浏览器检查通过；12关均有可回放三星解。桌面1440×1000、手机390×844与320×568覆盖工坊、选关、真实弹射获胜、失败/重试、下一关、进度持久化及离线模式。

Windows完整运行目录通过工坊换珠、风区挑战、单球发射和暂停测试；便携EXE已启动并加载新工坊/选关界面。原生鼠标复核时系统锁屏，未将锁屏截图当作游戏证据。独立Windows CI与公网结果见工作日志后续记录。
