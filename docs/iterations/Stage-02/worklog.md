# Stage-02 / v0.2.0 工作日志

## 2026-11-06 开始：弹珠工坊与挑战内容
- 用户要求不同大小/材质弹珠、增加内容、提升可玩性。
- 继承约束：场内单球、无飞行拖尾、每击减1、归零消除、无球龄/回合超时。此次不同尺寸要求覆盖旧版固定大球尺寸限制。
- 计划：4种材质×3种尺寸；保留无尽模式，增加12个固定挑战、发射次数预算、星级与本地进度；固定反射柱与连续气流机关。
- 物理设计：质量与密度/体积关联，发射器输入相同动能；重力加速度一致；不同法向恢复系数与磁性；气流按迎风面积/质量施力。全部为游戏调校参数，不声称精确模拟真实材料。
- 挑战关卡固定靶阵，回合间不推进、不补行；无尽模式保留逐轮上升/升级。挑战结束需实际回收或手动收球，不会在最后一次撞击时删除弹珠。
- 验证计划：保留已有21项回归；新增材质/尺寸、连续力、关卡结算/次数/星级、关卡可解性；桌面与手机工坊/选关/重试/进度持久化/离线测试；Windows完整目录及便携EXE验证。
- 浏览器路径：Browser plugin not available；沿用已有Playwright。实际手机、长期平衡和低端机性能仍未验收。
- 当前状态：设计与实现开始，尚未发布。

## 实现与第一轮验证
- 已实现4材质×3尺寸、工坊持久化选择、12关选关/目标/次数/星级/下一关/重试、无尽机关扩展。新材质使用实时球面高光/机加工纹理/哑光颗粒渲染，原金属场景保留；无球路拖尾。
- 物理验证：33项测试通过。新增固定动能、重力一致、法向恢复系数、磁性限制、局部气流、被动反射柱、挑战结算测试。
- 可解性：确定性角度/材质搜索为全部12关生成可回放三星解；验证数据tests/fixtures/challenges.json。搜索截断只用于模拟玩家主动收球，游戏本身无时间限制。
- 发现并处理：无尽靶阵上移可能与反射柱重叠，已在生成机关时过滤冲突位置；旧设计说明和当前规则分开保留。
- UI全流程与截图检查进行中，尚未发布。
