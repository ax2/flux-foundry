# Stage-24 风井的覆盖位置

第 19 关的上升风井贯穿两层核心与底部弹簧。小号橡胶在第 3 发的最后两次有效命中之间，多次被竖向气流托回。该间隔 17.6083 秒，其中前 16.23 秒没有接球，挡板来不及改变这部分路线。分量对照和原路线输入保存在 Stage-23/next。

将正常布局的风区左边界从 x=95 移到 x=105。保留 y=360、宽 230、高 270、横向风力 12 和竖向风力 −48。改变的是积木周边受风的覆盖位置，渲染与受力继续使用同一个羽化轮廓，镜像沿用坐标反射。弹簧、积木耐久、挡板、球材质和回收规则沿用原配置。

对比了更窄的风井、风井上边界、左右位置及多个风向。横向风增强在原病例更短，但在扩展主动首球新增 21.425 秒。采用平移方案是为保留风井托举作用，同时缩短这关多数高峰球路。代价是少量原首发需要下一发，48 局固定整局共多用 3 颗，静止挡板组的最长值增加 0.15 秒。

活动球沿真实连续外力和碰撞运动，接球次数自由，原球完整落底才回收。图集维持原始 PNG。测试观察上限只结束观察或拒绝搜索候选。
