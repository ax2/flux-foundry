# Stage-19 设计与取舍

2026-11-08。目标是降低强横向气流/低位残局的重复高抛，不增加操作、库存限制或球寿命。

## 实际原因

Stage18记录的22关橡胶大球触控输入有20.6833秒无命中。连续五次辅助接球没有target漂移，规划距实际接球0–16.7ms；预测出球速度与真实接触一致。前四次标准供能方案确实预测为miss，而非预测命中却未兑现。球从左侧x37–77被不断抛回强西向风层，剩余核心在x310/y570，额外能量不总是有用。橡胶大球质量0.35556，最大横向加速度1140px/s²，超过重力240。

## 实现

保留既有角度搜索和每次机械面变化上限0.32。仅在既有无进展接球条件已满足、剩1–2块且全部y>=540、横风最大加速度超过重力、标准方案找不到有效撞击时，依次尝试额外做功0/6000/12000。只接受法向撞击>55的预测方案；全部miss仍保留原方案。不会扣除现有速度/动能，实际变化只发生在随后真实挡板接触。零做功使用nullish默认而非逻辑或，避免被误换成18000。单次供能上限40000、总能量补充上限240000仍在。

预测工具可只读导出catch/outgoing/path，正式搜索不分配path；常规可达球路不增加供能搜索。标准26个候选，最坏104个；本机Node热身后100次/姿态微测中位2.7–5.7ms，不能当手机FPS。实际UI记录最大帧间隔325ms，不承诺低端设备帧率。

## 拒绝的试验

无阶段限制地提前降低供能会过早改变球路，原触控首球剩5HP，并破坏既有16关首球回归，拒绝。优先12000/6000/0试验首球剩2HP，恢复按最少额外做功优先。首轮矩阵跨进程启动期间短暂改过顺序，无法认证全部文件同源，保留为trial-*且不作为最终资格；全部七组在物理源码哈希冻结下重跑。
