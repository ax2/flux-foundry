# Flux Foundry v0.3.0 — 积木动力与有限库存

2026-11-07 · MIT · Windows x64 / 手机触屏 Web、PWA

- 六种积木：方形、三角、圆形、菱形、六边形、薄长条。弹簧积木在反弹时提供有上限的动能，每次有效撞击仍只减1。
- 解决低速停滞：可见救援气脉冲，反复脱困失败则机关退让，原弹珠在重力下落到底部，不按球龄消失。
- 重编18关，数字形成1–24的耐久阶梯；加入开关闸门、核心目标、风洞、反射柱、每日固定试炼。
- 每局有限弹珠：挑战5–12颗，限珠远征12颗；全部展示在顶部，点击调到下一发。4材质×3尺寸，场内始终一颗，无拖尾。
- 三星挑战与日期独立成绩；旧版成绩保留原存储，不套用到新布局。

平衡采用调整前后共9360次首球模拟，比较形状、数字、位置和弹簧供能；18个正常布局和18个镜像布局均有独立三星解回放。模拟不能代表玩家胜率或长期耐玩性，完整方法与数据见同目录 balance.md、balance.json、assessment.md。

本地验证：44项逻辑/物理测试、126项桌面与手机界面检查、Windows完整目录和便携EXE交互通过。手机实体设备表现、长期人类游玩平衡仍需反馈；Windows未签名。首次在线加载后可离线使用PWA，更新时关闭旧游戏标签再打开。
