# Stage-03 数值与布局对照

18关×5种布局变体×4种弹珠组合×13个固定角度=4680次首球模拟。每球最多模拟20秒，再模拟玩家主动收球；此上限仅用于测量，不是游戏寿命。变体分别为设计布局、全方块、耐久平坦（全场总HP与核心HP分别保持）、积木位置循环置换、关闭弹簧供能。均保留其余机关。首球样本不能代替真实玩家通关率；负荷指标=目标HP/(平均目标扣血×库存)，仅用于比较。
