# Stage-03 / v0.3.0 进行中 — 2026-11-07

## 用户要求与本轮目标
- 数字障碍统一称为积木；新增形状与可以补充动能的积木。
- 解决弹珠动能耗尽后永久停滞；不能恢复无提示的球龄清除。
- 耐久数字分层，计算形状、耐久与位置对难度的影响，再调整关卡。
- 每局固定数量弹珠，全部显示在顶部待发区；按已有单球偏好逐颗发射，场内仍一颗。
- 增加可重复玩的机制：开关/闸门、核心目标、每日固定试炼与限珠远征。

## 设计决策
- 新要求覆盖旧AGENTS中禁止任何增能和禁止自动脱困的笼统约束：仅允许有可见动力来源的增能积木/救援气脉冲，不强制恒速、不隐形增能。
- 防卡：连续局部停滞触发可见气脉冲；反复失败时积木与机关退让，保留弹珠、在重力下真实落底。不是按整轮时间删除弹珠。
- 六种几何：方、三角、圆、菱形、六边形、长条。碰撞几何与渲染轮廓一致。弹簧积木只给法向补充有上限的能量，每次有效撞击仍减1。
- 有限弹珠队列：挑战按关卡预算，远征固定12颗；排队弹珠可在发射前调序/工坊配置，飞行中锁定。
- 关卡重编为18关，使用低耐久通路、中耐久反射支点、高耐久核心；旧版星级保留原存储，不套用于新布局。

## 第一轮量化与调整
- 完成4680次首球对照：设计布局平均3.29次命中/4.60秒；关掉弹簧为3.02次/4.42秒。全方块与平坦耐久反而有更长平均驻留，说明形状/数值并非越复杂越耐玩，必须保留稳定支点与易开通路。
- 首球负荷指标对需要先开闸的核心关存在偏差，不能当作玩家胜率；同时使用完整关卡可解回放。
- 具体调整：第12关核心下增加中央弹簧薄板；第13关高耐久菱形改为稳定方形支点并移动下方弹簧；第16关保留一块高耐久方形作长廊锚点。第13/14/18关三星门槛按已找到的6/7/9颗通关路线调整。
- 防卡加入低速持续接触检测，避免贴面滚动绕过位置停滞判定。完整封闭平台测试已验证两次救援后退让并真实落底。

- 调整前/后各4680次首球对照，共9360次；第12关平均命中2.21→3.85、运行5.65→6.81秒；第16关3.65→4.63、4.16→4.87秒。第13关平均命中不变，时长仅小幅变化，不宣称明显改善。
