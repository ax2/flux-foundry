# Stage-31 靠墙接球与低位移动弹簧

第 9 波剩三块同高积木。六边形弹簧在左、移动三角弹簧在中、菱形在右。前两次接球时球心均在挡板可居中范围以外，两侧补能段已耗尽。横风在较高位置影响往返轨迹，实际接球和修正后的墙面反射均发生在横风区外。

当远征剩三块低位同高积木、其中至少一块为移动弹簧，且两侧补能均耗尽时，首次靠墙接球可以提前检查反弹。检查从连续 5.5 秒无有效命中、弹珠下降到 y=610 开始。球须仍向同侧墙运动。原挡板角度预报可命中时予以保留，否则只有 0.18 以内的倾角能在接球后 0.45 秒内预报有效命中才准备机械面。正常球体、墙面、挡板和气流计算继续处理实际轨迹。

钢珠首次准备时 vx=158.01，仍朝右墙。早期候选还覆盖 vx=-250.62、正朝场内移动的靠右陶瓷珠。进一步要求朝墙，可区分两种情况，保住原有陶瓷球路。
