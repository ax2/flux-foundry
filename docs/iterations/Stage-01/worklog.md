# Stage-01 工作日志

2026-11-06（Asia/Shanghai）

## 目标
实现可玩竖版多球反弹游戏，Windows EXE/完整目录、手机 Web，MIT 开源与首个 GitHub Release。

## 已有证据
用户提供一张参考截图，呈现顶部漏斗、数值几何靶、多球反射、收球控件。无原游戏源码或物理参数，不能声称精确复刻。

## 决策
- 原创工业材质主题；独立图像生成概念稿与透明素材图集已生成。
- TypeScript + Canvas 2D：共享游戏逻辑；Electron 提供 Windows 离线包；Vite 静态网页提供手机触屏版。
- 电容连锁、主动磁场、三选一升级；固定时间步长与真实三角边界反射。
- 每阶段保留完整 Windows 目录与 EXE，不创建项目 ZIP。
