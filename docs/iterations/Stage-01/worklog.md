## 目标
实现可玩竖版多球反弹游戏，Windows EXE/完整目录、手机 Web，MIT 开源与首个 GitHub Release。

## 决策

- 电容连锁、主动磁场、三选一升级；固定时间步长与真实三角边界反射。

## 用户修订：单球物理（2026-11-06）
用户明确要求：只需一颗更大弹珠、不显示发射后的轨迹、不带拖尾、物理规律优先，无需完全遵循参考截图。
- 当前实现取代本文件早期多球方案：单球半径 12（原为 5），渲染直径 24（原为 12）；没有 trail 历史数组，没有飞行路径线，也取消发射前长预测线，仅保留短方向标记。
- 移除强制 440 恒速；初速 350，恒定重力 240，以解析常加速度位移积分。碰撞恢复系数 0.94，保持切向速度、减少法向能量。精密回弹升级上限 0.99，不凭空增加能量。
- 自适应子步限制单步运动距离，避免高速穿透；低速静止接触不产生伤害。磁场使用软化中心力，连续施力，不瞬移、不重设速度。
- 靶阵每轮上移 39，每两轮补一行；初始伤害 3，耐久随单球节奏下调。蜂群升级替换为精密回弹。
- 背景漏斗里的装饰钢珠也已通过内置 Image Gen 移除，避免与单球方向冲突；原版背景可在早期 Git 提交追溯。
- 新增抛物线解析解、法向损耗/切向守恒、高速防穿透、单球不变量测试。当前 17 项单测通过。
- 旧 releases/v0.1.0 多球本地候选尚未发布，标为历史候选；最终单球版在 releases/v0.1.0-singleball。
