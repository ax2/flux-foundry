# 磁核弹阵 / Flux Foundry v0.1.0

首个公开可玩版本，按用户最新要求采用单球物理。

- 一颗较大的钢珠，无飞行轨迹、预测路径或拖尾；空金属漏斗、真实钢/铜/玻璃材质。
- 重力抛物线、带能量损耗的碰撞、三角斜面反射、自适应子步防穿透；没有强制恒速。
- 主动磁场作为连续外力，电容连锁放电，回弹/冲击/磁场三选一升级。
- Windows x64 便携 EXE，手机触屏网页/PWA；离线缓存、声音开关、简化特效、本地最佳分数、暂停和重开。
- 17 项逻辑与物理测试、36 条浏览器检查通过；Windows 便携 EXE 实际启动，单球计分和波次推进可见。

手机试玩：https://ax2.github.io/flux-foundry/

Windows 下载本 Release 的 EXE，直接运行。SHA256SUMS.txt 可校验下载；不提供游戏 ZIP。

限制：初版 Windows 未签名；手机交付 Web/PWA，尚非 Android APK/iOS 原生应用；真实手机、低端机性能、长期数值平衡和人工音频体验尚未验收。
