# v0.1.2 — 弹珠不再因超时消失

修复用户反馈的弹珠半途消失：移除22秒球龄清除和23秒回合终止。弹珠没有时间限制，只有完整落入底部回收槽或玩家主动「收球」才结束回合。

保留单颗较大的钢珠、无飞行轨迹/拖尾、重力与碰撞损耗、每次有效撞击数字减1且归零消除。平坦靶面可能托住已耗尽动能的钢珠，此时可以主动收球。

验证：21项逻辑/物理测试通过，包含60秒持续存在、底部边界与手动回收；36项桌面/手机浏览器检查通过；Windows完整运行目录启动、发射与暂停通过。
