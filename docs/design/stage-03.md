# Stage-03 架构与交互设计

积木将几何(kind)、数值(hp/maxHp)、动力/开关(power)与核心目标(core)分开组合。physics.ts提供统一轮廓，render.ts按相同顶点绘制，game.ts负责碰撞扣血、弹簧供能和机关状态。

弹簧每次碰撞最多增加22000内部能量单位，上限240000；以碰撞法向补充动能，保留切向速度。普通积木/墙/柱保持被动物理，不强行恒速；每次有效积木碰撞严格减1。以上为游戏单位，不声称现实焦耳。

有限队列queue保留本局全部弹珠，shots表示已发射数量；调序只交换未发射位置，工坊仅修改下一发。挑战预算5–12，远征12；飞行和暂停期间锁定操作。开始新局恢复预算，收球不返还库存。

防卡按局部位移及低速持续支撑接触识别，2.4秒触发可见气脉冲，每次0.25秒，最多两次。再停滞则机关退让，关闭磁场，保留同一球的速度、重力、墙碰撞，直到完整进入底部回收区。没有整轮时间上限。

清场关要求全部积木归零；核心关只要求核心归零，开关全部击碎才开放闸门。目标完成仍等弹珠正常回收/主动收球后结算。每日试炼以上海日期选关和镜像，普通/每日成绩独立。v3星级另用存储键，保留旧v2数据。

18关以弱耐久通路、中耐久支点、高耐久目标分工，并用首球对照及完整通关回放约束；详细量化方法见iterations/Stage-03/balance.md和assessment.md。
