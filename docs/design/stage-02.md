# Stage-02 玩法与验收计划

目标：让弹珠选择影响球路，让玩家有可重复挑战的明确目标。
交付：弹珠工坊、12个挑战、星级记录、固定反射柱/气流机关、无尽模式扩充。
不采用：多球、伤害升级、秒杀、隐形超时、以更高重力冒充更重弹珠。
验收：每种材质/尺寸可选择且物理不同；所有关卡具有模拟可解证据；手机可操作；失败/胜利/重试/下一关/进度恢复形成闭环；发布前档案同步。

## 实现参数与交互决策
材质密度比：钢1、黄铜1.08、陶瓷0.49、橡胶0.15；法向恢复系数分别0.94/0.86/0.97/0.80。半径9/12/16，质量按体积缩放；初速350/sqrt(相对质量)，重力240。磁场仅作用于钢珠，气流响应按面积/质量缩放。
挑战不推进靶阵，消耗发射次数而非时间；清场只在回收后判胜。每关有三星发射数、预算和提示，所有关卡直接可选；星级只保留最好结果。
保持原金属场景。钢珠使用既有图集，其余材质由实时球面渐变、高光、机加工线和哑光纹理表现。气流箭头属于环境标记，绝不绘制弹珠飞行尾巴。
