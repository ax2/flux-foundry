# Stage-01 设计与实现约束

2026-11-06。以用户截图的顶部发射、多球反射、数值靶阵为玩法参考；原创名为磁核弹阵 / Flux Foundry。

## 视觉系统
概念见 concept.png。黑化机加工金属、琥珀发射器、青色玻璃电容；顶部品牌/分数/波次，中央整块场地，底部磁场/收球与辅助操作。黑灰 #111719，暖金 #efbd79，青色 #75eff0。Bahnschrift / Segoe UI / 微软雅黑本地字体，不加载外部字体。

所有实际美术来自本次内置 Image Gen 的原创背景和透明图集：public/assets/arena.png、targets.png。实时数字、轨迹、粒子、磁场环与警戒线由代码绘制，是动态行为所需的有意设计，不使用静态概念截图冒充游戏。

## 交互与有意调整
- 相比概念的底部红线，实际警戒线位于发射口下方 y=184，因为靶块每轮上升，底部为回收槽。
- 概念英文按钮本地化为磁场、收球；增加中文说明、暂停、声音、简化特效、玩法与本地最佳纪录。
- 桌面宽屏加入左侧玩法文字、右侧简短主题文案；移动端只保留游戏机。
- 每轮 18 起始钢珠，以 65ms 间隔发射；每波增加 2 颗，升级可额外增加。初始冲击 1。
- 三角形按实际三条边反射；电容爆破对 135 单位内目标造成 3 + 冲击×2 的连锁伤害。
- 每轮一次磁场，3.8 秒起步，影响半径 230。每三波三选一升级。
- 所有球掉落或最长 23 秒后结束；单球最长 16 秒防无限水平反弹。收球立即推进回合。

## 架构
physics.ts：无 UI 的几何碰撞；game.ts：固定 120Hz 模拟、可复现种子、阶段状态机；render.ts：Canvas 材质图集与实时特效；main.ts：指针/键盘输入和可访问 HTML 控件；audio.ts：本地合成音效。Electron 只加载本地文件，沙箱开启，不向渲染器暴露 Node。Service Worker 按构建内容散列缓存完整静态资源，更新在旧客户端关闭后生效。

手机支持指触 Web；并不声称已交付 Android APK 或 iOS 安装包。真实设备、音乐创作、长期数值平衡仍需后续阶段验证。

## 最新规范：用户单球修订
此前的多球、光轨、球数升级均已废弃。当前只允许一颗活动钢珠，直径 24，无飞行轨迹和尾巴；重力 240、初速 350、法向恢复系数 0.94，切向不变，自适应子步防穿透。磁场是可主动部署的连续外力。靶阵上移每轮 39，每两轮补行，升级为回弹效率/冲击/磁场。初始概念图仅为历史视觉方向；用户已明确允许偏离截图，单球物理优先。
