# Stage-04 架构与交互

HOPPER_SLOTS共享原仓内12个位置；Canvas绘制真实材质珠，透明DOM按钮占相同位置，支持键盘和触屏；只映射queue.slice(shots)，不绘制额外待发球。每个最大尺寸球之间不相交，原场地不再损失独立库存栏高度。

积木耐久仅用数字，power/core以轮廓和机械纹路区分。功能解释集中在帮助/关卡简介，场地积木上不写功能名称，也不绘制进度条。

air.ts同时生成不规则风区轮廓与羽化受力强度；air-render.ts使用缓存透明遮罩、分层雾团及不同速度细流。render.ts在积木之前绘制气流，保护数字可读性。简化模式将时间固定；风阀在HP归零后反转所有风区向量，只执行一次，不额外扣任何积木数字。

侧壁段Rail有side/y/h/charges/maxCharges，普通墙仍被动恢复系数反弹；只有命中激活段才沿法向补能，最多22000内部单位，上限240000，每球每段3次。亮点表示余量；救援退让中不再补能。气流/磁场/救援都是显式外力，不对球强制恒速。

防卡新增passiveAnchor与passiveLoops：同一被动机关在12距离内四次接触且未取得数字进展时，沿用可见气脉冲。有效扣血清零无进展计数；两次救援后仍停滞才机关退让、原球重力落底。不存在按飞行总时长删除。

24关分四章，新增风井、风阀、双核心、窄门/强侧风；正常与镜像解独立，风阀状态在求解器每次候选复制中保持。因风区形状/动力改变，使用v4星级键，旧v3记录不删除。
